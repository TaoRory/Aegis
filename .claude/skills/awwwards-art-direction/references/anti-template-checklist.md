# Checklist chống "template AI"

Mỗi mục "có" ở cột trái là một điểm trừ. Website đạt chuẩn khi **không còn quá 2 mục**.

| Dấu hiệu template | Thay bằng |
|---|---|
| Hero 2 cột: chữ trái, minh họa/khối 3D phải, hai nút pill bên dưới | Headline tràn khung, chồng lên đồ họa; CTA là chi tiết nhỏ có cá tính (magnetic, mũi tên vẽ tay, nhãn mono) |
| Eyebrow viết hoa có gạch ngang trước mỗi tiêu đề section | Hệ nhãn có *nội dung*: `[02] Dịch vụ — 04 hạng mục`, số trang, tọa độ lưới |
| Lưới 3 thẻ bằng nhau có icon trong ô vuông bo góc | Danh sách typographic lớn, accordion, bảng có hairline, chữ cỡ lớn kèm số chỉ mục |
| Mọi thẻ đều bo góc 16–24px + shadow mềm | Cạnh thẳng hoặc bo rất nhỏ, đường hairline, khung có dấu "+"; shadow gần như không dùng |
| Gradient tím-xanh / glow cobalt / glassmorphism | Màu phẳng, kỷ luật 1+1+1, texture (noise, giấy) |
| Icon thư viện (lucide/heroicons) khắp nơi | Ký hiệu typographic (↗ ↪ → ⁄ №), đồ họa line-art riêng, hoặc bỏ hẳn icon |
| Fade-up mọi phần tử khi cuộn | Pin + scrub, split-line mask reveal, morph, vẽ nét, đếm số, chuyển màu nền theo chương |
| Font hệ thống/Inter mặc định ở mọi cỡ | Grotesk có cá tính cho display, serif nghiêng cho điểm nhấn, mono cho nhãn |
| Cỡ chữ hero ≤ 5rem, căn trái gọn gàng | Hero ≥ 9–12vw trên desktop, ngắt dòng có chủ đích, có thể chồng lớp |
| Section nào cũng `max-width` 1200px ở giữa | Có section full-bleed, chữ chạm mép, cột lệch, khoảng trắng lớn bất đối xứng |
| Badge pill "Tính năng nổi bật" | Chú thích kiểu bản vẽ, chỉ số mũ, gạch chân bằng nét vẽ |
| Footer 4 cột link nhỏ | Footer là một "màn kết": wordmark khổng lồ, CTA lớn, metadata mono |
| Nút "Bắt đầu ngay →" bo tròn màu brand | Nút có hành vi riêng (magnetic, text roll, vòng tròn lớn), microcopy theo ẩn dụ |
| Copy chung chung ("Giải pháp toàn diện", "Đối tác tin cậy") | Copy cụ thể, ngắn, có giọng: động từ mạnh, hình ảnh từ ẩn dụ |
| Không có khoảnh khắc nào đáng nhớ | Ít nhất 1 "signature moment" (xem SKILL.md) |

## Câu hỏi tự kiểm

1. Nếu bỏ logo đi, có nhận ra website này khác 100 website SaaS khác không?
2. Có khoảnh khắc nào người xem muốn quay video màn hình gửi bạn bè không?
3. Mỗi hiệu ứng có phục vụ ý tưởng lớn không, hay chỉ "cho đẹp"?
4. Chữ có đủ lớn và đủ dũng cảm chưa?
5. Màu accent có đang bị lạm dụng không?
