/** Sườn núi sinh bằng tổng các sóng sin (xác định, không ngẫu nhiên) */
function ridge(seed: number, base: number, amp: number, width = 1440, height = 800) {
  const points: string[] = [];
  for (let x = 0; x <= width; x += 24) {
    const t = x / width;
    const y =
      base +
      Math.sin(t * 5.2 + seed) * amp * 0.55 +
      Math.sin(t * 11.7 + seed * 2.3) * amp * 0.28 +
      Math.sin(t * 23.1 + seed * 0.7) * amp * 0.12;
    points.push(`${x},${y.toFixed(1)}`);
  }
  return `M0,${height} L${points.join(" L")} L${width},${height} Z`;
}

        ease: "none",
        stagger: 0.04,

                <a href="#trai-nghiem" className="hover:text-(--t-fg)">
                  Trải nghiệm
                </a>
              </li>
            </ul>
          </nav>

            Nhà Sương

          <SplitReveal as="h1" id="nha-suong-title" trigger="intro" className="mt-6 text-[clamp(3.4rem,1rem+8vw,9.5rem)] leading-[0.95] tracking-[-0.02em]">
            <span className="block">Nơi sương</span>
            <span className="block">
              <em>dừng lại</em>
            </span>
          </SplitReveal>

            <g key={i}>

            Ba cách <em>ở lại</em>
          </h2>
          <ul className="mt-16 border-t border-(--t-line)">
            {villas.map((villa, i) => (
              <li key={villa.name} className="nha-suong-villa grid items-center gap-6 border-b border-(--t-line) py-8 md:grid-cols-12">
                <span className="nha-suong-caps text-(--t-muted) md:col-span-1">0{i + 1}</span>

      </section>

      {/* Trải nghiệm */}
      <section id="trai-nghiem" aria-label="Trải nghiệm" className="border-y border-(--t-line) py-10">
        <Marquee duration={40}>
          {moments.map((m) => (
            <span key={m} className="px-10 text-[clamp(2rem,1rem+3vw,4rem)] whitespace-nowrap" style={{ fontFamily: "var(--t-font-display)" }}>
              <em>{m}</em> <span className="text-(--t-accent)">·</span>
